# Antigravity Agent Rules

*   **Lesson Number in Headings**: Whenever taking notes from a course transcript or slide, ALWAYS prefix the main section headings with the corresponding lesson number (e.g., `## Bài 70: Mở rộng quy mô và Tính sẵn sàng cao` instead of just `## 1. Mở rộng quy mô...`). This helps keep the notes perfectly synced with the course structure.
